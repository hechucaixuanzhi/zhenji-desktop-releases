# v0.1.13｜个人与项目记忆管理

## 对现有用户的使用变化

相对 v0.1.12，本次接通“设置 → AI 设置 → 上下文与记忆”的记忆管理。现在可以在“个人”和“项目”之间切换，选择具体项目，处理待确认记忆，并修改或删除已保留记忆。

例如，想更新某个项目的人物约定时，现在可选中该项目，找到已保留条目并点“修改”；保存后重新读取最新内容，后续符合权限的上下文和项目读取使用更新后的记忆。待确认条目可以“保留”或“忽略”。保存失败会保留编辑文字，可重试或取消；空白和超过 600 字符的内容会提示校验。

本次新增的是上述管理闭环及记忆变更后多实例读取的一致性。单章稿保存、登记与继续创作等 v0.1.12 已上线能力沿用原流程。

## 使用前要做什么

已安装 Windows 桌面壳 0.1.9 的用户无需重新安装，也无需迁移旧数据。请先保存当前内容，再正常关闭并重新打开真迹，加载新的界面。

- [官方 Windows x64 安装器 0.1.9](https://github.com/hechucaixuanzhi/zhenji-desktop-releases/releases/download/v0.1.9/Zhenji-0.1.9-x64-Setup.exe)

v0.1.13 是本次产品界面与服务版本，安装器版本仍为 0.1.9；未重打或改名旧安装器。

## 保持不变与范围

保留既有作品、聊天、项目和已保存记忆。修改或删除记忆不会追溯改写已经发送的聊天或已保存文章。个人与项目记忆按账号和项目权限分别管理；归档或删除的项目不开放继续修改。

本次沿用已确认的设置样式，不增加项目左栏菜单、独立抽屉或已忽略管理中心。新记忆自动提取、语义召回、七家模型适配及其余未交付的记忆功能继续按原排期推进。

已完成真实安装版的线上只读管理入口、个人/项目内容及空态、账号隔离和正常关闭重启验收；管理写入、失败保稿和后续消费在隔离真实 API/数据库及真实安装版中验证，未为验收修改生产用户记忆。本包新增真实模型调用与费用均为 0。仅发布 Windows Desktop Beta，不代表整个 P6、S03 或 v1.0.0 已全部完成。
