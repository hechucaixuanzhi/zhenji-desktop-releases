# 真迹 v0.9.0 预览版

- 小迹输入框的加号可以添加附件，也可粘贴长文本。处理完成后能预览，再随问题一起发送。每条最多 5 个附件、合计 25 MiB，另有格式、单件及预览期存储限额。
- 引用能定位到原回答或选中的片段。作品或资料的改稿先展示待确认内容，用户确认后写入。
- 输入框、模型菜单及工作区更新。Task 可在小迹中发起，Ask 卡片确认后继续任务。明确请求搜索或读取公开网页时，支持的 DeepSeek 渠道会带回可核对的来源，实际可用性取决于账号和模型设置。
- 现有客户端保存编辑后刷新或重开即可加载 Web 更新。需要升级 Windows x64 桌面壳时，使用本版本桌面 Release 的 0.1.10 安装器。安装器未签名。
- 本版暂停新受理账号永久注销，MiniMax M Plan 的真实渠道验收延后。
