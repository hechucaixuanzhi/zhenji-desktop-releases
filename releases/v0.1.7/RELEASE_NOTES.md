# 真迹 v0.1.7｜Project 自主取材

2026-10-15 · Windows Desktop Beta

## 更新内容

- 小迹可自主按需查阅当前项目的资料与已确认记忆，手选来源保留为可选操作。
- 取材完成状态按实际读取范围校验；未取得或只取得部分依据时明确提示。
- 保留已有的项目来源选择、作品读取、私信和隐私设置。

自主取材在当前会话有效的项目读取授权范围内进行，目前支持 DeepSeek 接入。读取按任务选择相关内容，不代表已阅读整个项目的全部正文。

## 交付情况

本更新已部署。两类来源的真实自主读取与完整取材结果、安装版桌面目标验收及约304秒运行观察已通过。其他后续功能按各自发布说明交付。

## 如何使用

已有用户正常关闭并重新打开真迹桌面应用即可加载线上更新。本次没有新安装包，桌面壳与安装器继续使用 **v0.1.3**。

首次安装请从[官方安装器页面](https://github.com/hechucaixuanzhi/zhenji-desktop-releases/releases/tag/desktop-v0.1.3-00367ee991ad)下载 Windows x64 版本，并核对SHA256：
