# 真迹 v0.1.5 Windows 桌面内测更新

发布日期：2026-10-14。

## 本次更新

- 小迹接入项目资料和已确认记忆的授权读取，支持选择与移除来源。
- 保留成熟桌面界面及已有Work/B功能，完成真实安装版的来源操作和账号隔离验证。
- 改善发布交接与恢复流程；正常关闭、重新启动及上线观察已通过。

## 如何使用

已安装真迹的用户正常重新打开应用即可加载线上界面。本次沿用**0.1.3桌面壳及安装器**，无需重新安装。

首次安装请使用[官方0.1.3安装包及校验文件](https://github.com/hechucaixuanzhi/zhenji-desktop-releases/releases/tag/desktop-v0.1.3-00367ee991ad)。本版没有新安装包，不将旧安装器重命名为0.1.5。

## 说明

功能按账号权限、来源授权和实际服务开关提供。这是Project阶段的桌面内测更新，整体正式版建设继续推进。社交通知/隐私新设置等后续能力在实际发布时另行说明。

本版已上线的是显式选择来源的读取路径。小迹自主按需读取项目资料与记忆仍需补齐；完整体验中手选来源仅为可选操作。目前不将Project完整体验标为完成。

发布与安装器校验信息见`release-manifest.json`。公开仓库只提供更新说明和制品信息。
