# v0.3.0｜Task、Ask 与真实联网

本次集中上线小迹的有界写作任务、问题卡续写和真实搜索／网页读取。

## 现在可以怎么用

- 在小迹的正式任务入口描述本次写作目标，查看预检和费用上界后明确开始。首版使用已验的有限写作流程；查看问题卡并点击“确认整组回答”后，同一个任务继续生成正文。刷新后可以查看任务、问题及结果。
- 明确要求搜索，或提供公开网页链接并要求读取。小迹通过已验渠道取得内容后回答；回答中的来源可展开查看，搜索摘要与实际读取的正文分别显示。来源范围以实际取得和供给的内容为准。
- 任务状态、问题卡和相关站内提醒保持关联；停止和 UNKNOWN 状态保留，不会将不确定结果自动当作成功或重复执行。

Task／Ask 不会替你自动保存、登记作品或授予资料读写权限。后续输入受到迟到回执保护。首版实际渠道验收覆盖既有 DeepSeek 型号；不表示所有厂商、Plan、任意多步任务或所有公开网站均已可用。

## 更新方式

先保存正在编辑的内容，再刷新页面或正常重开真迹即可。**已安装 0.1.9 无需重新安装。**

业务版本为 v0.3.0；Windows 安装壳仍为 0.1.9。继续使用[原 Windows x64 安装器](https://github.com/hechucaixuanzhi/zhenji-desktop-releases/releases/download/v0.1.9/Zhenji-0.1.9-x64-Setup.exe)，未重建、上传或改名安装器。新桌面版本检查桥和 v0.9 后继功能不属于本次发布。
