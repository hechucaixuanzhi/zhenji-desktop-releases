# 真迹 v0.1.15 · 记忆编辑恢复修复

## 对现有用户的使用变化

- 编辑记忆时，条目被其他窗口删除或忽略后，完整修改文字仍可查看、复制；取消编辑后可以继续切换个人/项目范围、项目及页面。
- 保存结果暂时无法确认时会先核对。已经保存成功、仅列表刷新失败时，保留真实保存结果，避免重复提交。
- 沿用原设置布局和记忆操作样式，本次仅修复 R2-05 的保稿与安全退出。

## 安装与数据

已安装 0.1.9 的用户无需重新安装。先保存正在编辑的内容，再正常退出并重新打开真迹即可。

本次仅更新 Web 界面，API 与 116 条迁移记录保持当前 C04 版本，多章稿和现有小迹能力继续保留。原生安装器沿用官方 0.1.9，未重打或改名；没有新增模型调用或费用。
