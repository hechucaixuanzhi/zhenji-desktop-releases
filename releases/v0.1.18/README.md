# v0.1.18｜正文格式与保源阅读

## 使用变化

- 创作稿可明确选择“纯文本”或“Markdown”，整稿各章共用所选格式。
- Studio、沉浸写作、正文预览和历史阅读按同一格式显示，保留中文、诗行、缩进与空行。
- 切换格式先确认并保存，保留源文字；Markdown 标记在纯文本中会直接显示，视觉效果可能改变。
- 保存点、登记版本和恢复保留对应格式，继续创作不会改写旧登记内容。
- 正文预览可下载当前章的 `.md` 或 `.txt` 原文。
- 修复保存结果不确定时，错误提示遮挡保存按钮、影响重试的问题。

旧稿保持原有解释；需要使用新格式时，在 Studio 先执行已有的“转新版”。Markdown 使用声明的安全语法子集，不执行原始 HTML，不自动加载外部图片。
