# v0.1.14｜多章稿编辑与完整保存

## 对现有用户的使用变化

相对 v0.1.13，现在可以在新版私稿里把单章稿切成多章，新增、删除、改名和调整章节顺序，并分别修改各章内容。切换为多章时，原正文会完整保留在第一章；切回单章时，各章按原顺序合并，章名写入正文作为标题，正文不会因切换丢失。

每次确有变化且保存成功时，时间线新增一个可恢复的完整作品时间点；没有变化、保存失败或发生冲突时不会虚增时间点。不同章节从同一基线编辑可以分别保存；同一章节或目录结构已过期时，界面会提示冲突并保留当前输入，方便核对后再保存。多章稿也可恢复、登记为作品，并从登记后的下一份私稿继续创作。既有已登记正文、证书与固定历史不会因本次更新被改写。

## 使用前要做什么

已安装 Windows 桌面壳 0.1.9 的用户无需重新安装，也无需迁移旧稿。请先保存当前内容，再正常关闭并重新打开真迹以加载更新后的界面。

v0.1.14 是本次网页界面、API 与数据库能力版本；原生安装器没有变化，继续使用真实 0.1.9 制品。
