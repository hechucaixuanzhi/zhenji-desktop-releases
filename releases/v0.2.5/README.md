# 真迹 v0.2.5 Windows Desktop Beta 更新说明

真迹预览版 v0.2.5：登录、授权引用与正文读取修复。

- 已登录时点击“进入真迹”会显示等待反馈；暂时失败可以重试，无须先退出再重进。认证页恢复最小化、最大化／还原和关闭按钮。
- `@` 选择作品后，在原输入区上方显示本次挂载卡。修复冷加载、首次会话和授权确认的衔接；失败保留输入与引用，迟到回执不会清掉后续新输入。
- 询问“你能找到我给你授权的文章吗”等目录问题时，小迹准确列出已授权目录；这一步不会读取正文或启动模型生成。
- 明确要求阅读或总结已授权作品时，按实际授权和选取范围供给正文，并显示准确来源。只有正式回执通过才显示“已供给所选正文”，不会把目录、授权标记或模型自述当成读过全文。

原 AI 授权改稿与确认保存继续保留。**Task 新发起与真实联网仍未开放**；已有任务、来源及执行／费用待核记录继续保留，不会因刷新自动重发。

请先保存正在编辑的内容，再刷新页面或正常重开现有 **0.1.9** 真迹客户端即可；无需重新安装。本次仅更新 Web／API，没有重建、改名或上传安装器。
