# v0.1.19｜创作工作区统一与登记精简

## 使用变化

- 创作编辑统一到小迹右侧工作区；个人主页的作品、草稿及继续创作入口进入同一编辑面。
- 保存、章节与登记集中在同一工具栏；预览、原文下载和恢复沿用当前稿件与对应保存点。
- 续版沿用原署名和声明，修改说明可以留空；首次登记的其他信息收进选填区。
- 编辑中的文字继续受到保存、离开和恢复保护；切换聊天不重置稿件，已登记的旧版本保持只读。
- 旧作品列表入口转到个人主页作品栏目，旧沉浸链接保留稿件身份进入统一编辑面。
- 正文显示和原文下载继续遵循已有格式信息；界面收起格式选择／转换及独立沉浸入口。

本次更新创作编辑与登记。站内查找／公开正文AI读取故障、资料栏设计讨论及另列的小界面修复继续按各自任务处理，不包含在本版本修复声明中。
