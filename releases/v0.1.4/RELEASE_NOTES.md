# 真迹 v0.1.4 Windows 桌面内测更新

发布日期：2026-10-12。此版本集中记录 v0.1.3 后已经上线的作品读取、跨会话读取及桌面界面更新；不重新部署服务，不重新生成安装器。

## 本次更新

- 统一首页、导航、小迹、作品阅读、编辑与登记、个人中心、设置、通知、帮助及反馈等桌面页面的外观和交互。
- 改进页面返回、输入暂存保护、账号切换隔离、隐藏页面消息处理，以及设置搜索与定位。
- 新增产品使用指南入口、章节检索及同源 Markdown 文档；小迹自动按需读取指南的能力仍在后续计划内。
- 纳入已经上线的本人 Work/Draft 授权读取及跨会话 B 的授权读取、撤权与账号隔离。实际可读范围依照产品授权，不扩大到任意用户内容。
