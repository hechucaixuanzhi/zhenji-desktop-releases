# v0.1.17｜小迹输入、消息与来源阅读

## 使用变化

- 小迹输入框接入统一样式；切换聊天或刷新时，同一窗口内的未发送文字可以保留。
- 回复的反馈备注、引用、重生成及删除接入实际操作；失败时保留可恢复内容。
- 右栏可读取准确的登记版本、切换和关闭版本标签，区分项目资料与当前聊天资料。
- 来源显示所读修订、范围及裁剪情况；聊天与项目的读取授权分别管理。
- 修复 Windows 安装版复制消息失败的问题。

例如：在聊天 A 写下未发送内容，切到聊天 B 查看资料，再返回 A，可继续原来的输入；查看登记作品时，可选择准确版本，而不是被静默切到最新版。

## 使用方式

已安装 0.1.9 无需重装。先保存正在编辑的内容，再重新打开真迹。

- [Windows x64 安装器 0.1.9](https://github.com/hechucaixuanzhi/zhenji-desktop-releases/releases/download/v0.1.9/Zhenji-0.1.9-x64-Setup.exe)
- SHA-256：`92c44080863c42e724af9928adc1e04c61265e15eb15d7bcfee5d08bf16a3cde`

输入恢复限当前设备、当前标签页和对应账号，不承诺关闭标签页后永久保存。本次沿用现有 API 和数据库，没有新增收费模型验证或重置任何额度。附件、工具、任务队列及编辑重发等后续能力不计入本次交付。

本次是 Windows Desktop 内测更新，不代表网页版已全面公开。
