# 真迹 v0.1.12｜单章稿登记与继续创作

真迹 Windows 桌面内测现可在 Studio 新建单章稿，或明确转换旧稿后保存；登记为私有作品后自动进入同一作品的下一态续作。再次登记形成固定历史版本，桌面可查看保存点与登记周期。

未保存修改与历史恢复继续保护当前创作；旧多章稿件可完整恢复到兼容编辑模式，由作者明确决定是否再转换。本人作品的当前正文与固定历史地址可供既有小迹读取能力按权限使用，公开阅读仍受作品可见性约束。

## 桌面使用

沿用 **0.1.9 Windows x64 桌面壳**，已安装用户无需重装。先保存当前内容，再重新打开真迹以加载服务更新。
