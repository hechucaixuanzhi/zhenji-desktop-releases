# v0.2.0｜正文排版、资料编辑与等待队列

本次更新真迹的界面与服务，沿用 Windows 桌面壳 0.1.9。先保存当前编辑，再刷新页面或重新打开真迹即可，无需重新安装。

- **正文可以主动排版。** 在原 Studio／作品正文区使用标题、加粗、斜体、列表、引用、链接等工具；支持相应的选区操作及 Ctrl+B／Ctrl+I。纯文本首次启用会先确认，正文与格式通过原保存入口一次保存，刷新后保留。
- **资料可以持续编辑。** 在原项目／会话资料入口修改标题和正文并保存；刷新读回当前修订。从回答采用资料时保留真实来源，保存回执不会覆盖保存期间后来输入的内容。
- **回答过程中可以继续排队提问。** 后续内容进入等待列表，可编辑、调整顺序或取消；刷新保留状态。停止或执行结果尚未明确时暂停后续推进，避免意外重发。

联网搜索和网页读取本次未开放。超长、密集短段正文仍可能出现输入延迟。此前 WORK／CHAT 正文显示和自然编辑能力继续保留。

已有 0.1.9 安装无需重装。首次安装可继续使用 [Windows x64 安装器 0.1.9](https://github.com/hechucaixuanzhi/zhenji-desktop-releases/releases/download/v0.1.9/Zhenji-0.1.9-x64-Setup.exe)，SHA256 `92c44080863c42e724af9928adc1e04c61265e15eb15d7bcfee5d08bf16a3cde`。本次没有重新打包、上传或改名安装器。

此版本仍为 Desktop Beta／预览版，不代表 v1.0 GA。固定运行源码 `7c6ba34f38097b07869030a27ca8d5990e4c5b29`；U07-EDIT-03/API-01、C05-MAT-01、A03-QUEUE-01 的实现、接线、验收与部署结果均记录在各自原包 REPORT。
