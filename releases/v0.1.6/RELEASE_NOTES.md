# 真迹 v0.1.6｜社交通知与隐私

2026-10-14 · Windows Desktop Beta

## 更新内容

- 启用私信，支持所有人、我关注的人、互关、不接收四种接收范围。
- 支持私信、评论、回复、新关注、点赞、收藏六类站内提醒偏好。
- 支持点赞、收藏、关注、粉丝、互关五类详情公开控制，默认不公开详情。
- 改善通知去重、私信历史读取与已读处理，同步产品使用文档和设置搜索。
