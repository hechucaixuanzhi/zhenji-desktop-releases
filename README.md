# 真迹 Windows Desktop Beta

本仓库用于发布真迹 Windows x64 Desktop 的 Beta 更新说明、安装制品与 SHA-256 校验信息。

## 当前版本

- 产品界面与服务：[v0.1.16 内容保存与恢复修复](https://github.com/hechucaixuanzhi/zhenji-desktop-releases/releases/tag/v0.1.16)。桌面壳沿用 0.1.9。
- [下载 Windows x64 安装器 0.1.9](https://github.com/hechucaixuanzhi/zhenji-desktop-releases/releases/download/v0.1.9/Zhenji-0.1.9-x64-Setup.exe)。
- 已安装 0.1.9 无需重新安装，先保存当前内容，再重新打开真迹即可。本次未重打或改名安装器。

## 安装与校验

- 平台：Windows x64。
- 当前安装包尚未进行代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。
- 下载后请使用 Release 页面列出的官方 SHA-256，或随安装包提供的 `.sha256` 文件进行校验。
- 当前不支持桌面壳自动更新；有新安装器时从本仓库手动下载安装。仅界面或服务更新时，按对应 Release 说明使用既有桌面壳。
