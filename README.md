# 真迹 Windows Desktop Beta

本仓库仅用于发布真迹 Windows x64 Desktop 的公开 Beta 二进制制品与 SHA-256 校验信息。

## 安装与校验

- 平台：Windows x64。
- 当前安装包尚未进行代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。
- 下载后请使用 Release 页面列出的官方 SHA-256，或随安装包提供的 `.sha256` 文件进行校验。
- 当前不支持自动更新；后续补丁需要从本仓库手动下载并安装。

## 范围边界

- 本仓库不包含真迹产品源码、内部治理文档、Issue、测试账号或生产配置。
- 此处的发布仅代表 Windows Desktop Beta，不代表 Web、Mobile 或其他客户端已全面公开。
- Beta 版本不是 v1.0 GA。
