# 真迹 Windows Desktop Beta

本仓库用于发布真迹 Windows x64 Desktop 的 Beta 更新说明、安装制品与 SHA-256 校验信息。

## 当前版本

- 产品界面与服务：[v0.1.4 桌面内测更新](https://github.com/hechucaixuanzhi/zhenji-desktop-releases/releases/tag/v0.1.4)。
- 当前桌面壳及安装器仍为 **v0.1.3**：[下载安装包与校验文件](https://github.com/hechucaixuanzhi/zhenji-desktop-releases/releases/tag/desktop-v0.1.3-00367ee991ad)。
- v0.1.4 沿用既有安装器；已安装用户正常重新打开应用即可加载线上界面，不需要重新安装。

## 安装与校验

- 平台：Windows x64。
- 当前安装包尚未进行代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。
- 下载后请使用 Release 页面列出的官方 SHA-256，或随安装包提供的 `.sha256` 文件进行校验。
- 当前不支持桌面壳自动更新；有新安装器时从本仓库手动下载安装。仅界面或服务更新时，按对应 Release 说明使用既有桌面壳。
